## 尚未充分验收及边界

长期稳定性、持续多轮、并发消息和批处理、限频下的延迟及平台出站重复保护尚未充分验收。单次成功不能推断长期可靠性，不提供生产保证或即时 SLA。

每条微信入站对应独立根线程，不跨线程猜测上下文；回程仍受精确团队/频道/user/bot/app 绑定、完整事件映射有效期、最终文字标记及微信上下文 TTL 限制。缺少可信身份映射、上下文过期或发送结果不确定时失败关闭，不能通过放宽身份校验、延长 TTL 或盲目重发来维持表面成功。

CodeRabbit CLI 未安装，遵守“不安装全局工具、不自行授权”的要求；仓库现有 CodeRabbit 实际报告少于 10 星而跳过自动审查；未执行手动外部代理指令，是否手动触发留给用户决定。

容器普通在线构建的 npm DNS 在此云环境内报 `EAI_AGAIN`，宿主 npm 正常。为避免更改网络安全设置，容器验证使用云环境已下载的 npm 缓存作临时离线构建；缓存不进入仓库或运行镜像。离线镜像构建、UID 1000、只读根目录、唯一状态目录写入、SQLite、运行锁、正常与过期健康检查均实际通过（运行时禁用网络）。正常部署仍需要容器构建网络能解析 npm 域名。

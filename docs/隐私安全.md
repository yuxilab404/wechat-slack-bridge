# 隐私、安全与配置

## 数据和凭据

`secrets/slack.json` 由用户一次安全配置，只有两个字段：`slackBotToken` 与 `slackAppToken`。可读文件或只读 secret mount 均可，但文件必须由运行用户读取，模式为 0600 或 0400。程序不接收命令行 Token，也不从 URL 读取密码；API/CDN 地址不是凭据。

扫码后 `state/session.json` 保存微信 `bot_token`、扫码者标识、bot 账号和 API 地址，使用 0600 临时文件、fsync 和原子重命名；目录 0700。状态数据库含消息正文、上下文 Token、媒体 URL、AES 参数及身份映射，是敏感数据，默认最长保留一天负载。备份也属于敏感数据，不进 CI/镜像/日志。SQLite 删除和 WAL 截断不能保证 SSD、快照或外部备份物理擦除；需要用户管理磁盘加密和备份保留。

媒体解密后以原始字节上传 Slack；回程授权下载后加密上传微信 CDN。微信、Slack、官方 ChatGPT 自动化各自按其权限处理内容。AES-ECB 是上游协议要求，不能擅自改成其他模式；它不是桥端新增的端到端加密保证。

撤销：停止桥，在 Slack 撤销机器人和应用级令牌/卸载应用，关闭对应官方事件自动化；在微信解除该连接或撤销登录。仅删除本地文件不等于撤销服务端令牌。确认服务端撤销后，按用户的数据保留要求销毁本地文件和备份。

## 网络边界

业务请求仅 HTTPS，精确域名白名单，不接受用户信息、非 443 端口、私网/环回/链路本地/保留地址。DNS 在连接时解析并检查所有返回地址，避免检查后重新解析造成的重绑定。所有 HTTP 重定向拒绝；扫码协议级 `redirect_host` 也必须先通过显式白名单。Slack 下载携带令牌仅访问固定 `files.slack.com`，不会把令牌送到配置新增的媒体域名。

默认域名是上游官方协议域名，不是私人服务器。若真实登录返回新的官方分区域名，用户需核验归属后明确添加 `apiHosts`；不要用通配符。未知 CDN/下载重定向会失败关闭，不为“能下载”放宽到任意域名。

请求 45 秒超时；流式计数限制响应体，JSON 默认 2 MiB，单文件按配置限额。媒体类型检查 MIME 与图片头；不解码图片或剥离元数据，接收方仍应把图片当不可信文件。原始内容中的指令不能改变身份/频道策略。

所有应用日志和错误是固定中文文本，不记录正文、令牌、AES 密钥、签名 URL、原始异常或 SDK 请求体。二维码只允许用户主动运行的交互终端展示，不进入后台日志。第三方工具、Node 自身警告及 npm 输出不属于应用自有日志。

## 严格配置

未知字段报错，配置错误不会原样输出输入。

| 字段                            | 说明                                                        |
| ------------------------------- | ----------------------------------------------------------- |
| `team` / `channel`              | 唯一 Slack 团队和专用频道                                   |
| `dotUser` / `dotBot` / `dotApp` | 同时匹配的正式回复身份                                      |
| `bridgeUser`                    | 桥机器人身份，不得等于 dot                                  |
| `secretFile` / `stateDir`       | 用户管理的凭据文件与唯一可写状态目录                        |
| `apiHosts` / `mediaHosts`       | 精确官方主机白名单，无通配符                                |
| `maxFileBytes`                  | 1 KiB～20 MiB，默认 10 MiB                                  |
| `maxStateBytes`                 | 1 MiB～1 GiB，默认 100 MiB，另加部署磁盘配额                |
| `ttlMs`                         | 1 分钟～7 天，默认 1 天，负载保留上限                       |
| `contextTtlMs`                  | 1 秒～1 天，默认 1 小时，桥本地保守限制，不宣称服务端有效期 |
| `settleMs`                      | 1～60 秒，默认 5 秒，编辑合并窗口                           |
| `finalPrefix`                   | 最终回复标记，默认“【最终回复】”                            |

`.env.example` 只有假路径；程序不自动读取 `.env`。实际 Slack 标识是用户配置，示例与测试均为虚构值。使用新账号必须使用新状态目录。

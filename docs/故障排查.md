# 故障排查与验收

| 现象                    | 排查                                                                                                               |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 配置/凭据错误           | 核对 JSON 字段、文件所有者与 0600/0400 权限；错误不回显敏感输入                                                    |
| Slack 有消息但 dot 不醒 | 检查用户是否给当前个人 dot 建了受限官方事件自动化、应用已入频道、允许桥 bot 作者和线程事件；@ 或 DM 不代表订阅成功 |
| 只有图片准备消息        | 查图片段状态；必须完成外部上传才发就绪标记                                                                         |
| dot 回了但微信没收到    | 检查 team/channel/user/bot/app，回复的 thread_ts，最终标记及原微信 context 是否仍有效                              |
| 新消息持续失败          | 查看固定中文错误分类；检查令牌撤销、频道成员权限、限流和 session 过期                                              |
| 地址被拒绝              | 核验官方分区主机再显式配置；禁止添加任意 URL、私网或通配域名                                                       |
| `uncertain`             | 人工对照远端实际消息；程序不会自动重送，勿清空队列碰运气。当前没有“强制重试”命令                                   |
| 上下文过期              | 由本人发新微信消息，旧回复不移植到新上下文                                                                         |
| 状态容量已满            | 停服务并备份敏感状态，核对磁盘配额，调整容量；保留墓碑，否则历史重放可能重复转发                                   |
| 进程运行锁              | 同一 state 只能运行一个实例；异常断电锁在 120 秒失效，不要同时启动多个副本                                         |

## 用户醒来后的一次性配置

1. 在安全文件配置桥 Slack bot/app 令牌，确认必要权限与专用频道成员。
2. 在非敏感配置填写真实团队、频道、桥身份与 dot 三重身份；不要把这些贴到公开仓库。
3. 用户在自己的个人 dot 建立受限官方 Slack 事件自动化，采用文档里的就绪/最终标记约定。桥不修改现有临时任务。
4. 在最终部署主机交互扫码，由扫码身份绑定本人私聊。若返回未知官方分区域名，核验后补白名单。
5. 进行下列真实验收，合格后再决定生产部署。

## 真实验收清单（尚未执行）

微信文字 → Slack 真消息；微信图片 → Slack 可打开的真文件；dot 文字 → 同一微信会话；dot 图片 → 微信 IMAGE，并比较原始字节或下载文件哈希。再验证至少三轮连续对话、并发/乱序、断网后重启、部分图片失败、错误身份和陌生人拒绝，观察官方自动化批处理与重复出站保护是否阻止后续回复。

离线测试覆盖真实 HTTP 假服务的四条适配器路径，不使用真实账号。Socket Mode SDK 与平台自动化的端到端连通性、微信真实二维码、真实 CDN 地域地址和图片显示效果需要现场验收。不得把离线成功描述为“微信已接通”。

首次启动无转发：检查是否已读取状态目录 `启用确认.txt` 并由扫码本人发送整行文字。缺少合法 `create_time_ms` 的确认或业务消息会隔离，不能用本地接收时间补齐；确认同毫秒的业务消息请重新发送。持续“微信同步暂停”可能是未来消息时间或本机时钟回退，检查主机时间同步后重试；不要删状态或回退启用边界。未确认时消息只在本机限时缓冲，不上传图片或发 Slack。
